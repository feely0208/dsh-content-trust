dsh-content-trust · rules
$ dsh-content-trust --list-rules
 
深鲸守护 · 外部内容信任边界 —— 4 条规则
 
[high] CT-RAW-TO-PROMPT
把外部内容直接拼进 prompt（无隔离）
依据：OWASP Top 10 for LLM Applications — LLM01 Prompt Injection（含 Indirect Prompt Injection）；NIST AI 100-2 · 间接提示注入
 
[medium] CT-NO-DELIMITER
拼接外部内容时没有分隔与来源标注
依据：OWASP Top 10 for LLM Applications — LLM01；业界缓解措施建议：用明确分隔符包裹不可信内容并声明其性质
 
[critical] CT-EXEC-CONTENT
把外部内容里的「指令」提取出来执行
依据：OWASP Top 10 for LLM Applications — LLM01 + LLM05；间接提示注入导致的实际攻击链
 
[high] CT-BROWSER-CRED
agent 浏览器上下文里注入了用户凭证
依据：OWASP Top 10 for LLM Applications — LLM01 / LLM06（Excessive Agency）；间接提示注入 + 已登录会话 = 可代替用户操作
